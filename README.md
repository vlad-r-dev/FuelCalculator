# ⛽Fuel Calculator

A simple website that helps drivers calculate fuel consumption for a trip.

## Features

- Calculate fuel consumption
- Calculate remaining fuel in the tank
- Calculate the remaining driving range

## Technologies

- HTML
- CSS
- JavaScript

## Website Language
- Ukrainian
